# Alice IDE

IDE-помощник на базе **YandexGPT** (технологии «Алисы»), работающий по аналогии с Cursor IDE.

## Возможности

- **Чат с AI** — общайтесь с Алисой о коде на русском языке
- **Контекст кода** — передавайте содержимое редактора или выделенный фрагмент в запрос
- **Применение изменений** — кнопка «Применить изменения» для вставки сгенерированного кода
- **Стриминг ответов** — ответы отображаются постепенно, как в Cursor

## Быстрый старт

### 1. Настройка Yandex Cloud

1. Создайте [аккаунт Yandex Cloud](https://console.cloud.yandex.ru/)
2. Создайте каталог (folder)
3. Включите [YandexGPT API](https://cloud.yandex.ru/docs/ai/llm/quickstart)
4. Создайте API-ключ в разделе IAM

### 2. Локальный запуск

```bash
# Клонировать и перейти в каталог
cd alice-ide

# Скопировать переменные окружения
cp .env.example .env
# Отредактировать .env — указать YANDEX_API_KEY и YANDEX_FOLDER_ID

# Запуск бэкенда
cd backend
pip install -r requirements.txt
python3 main.py

# В другом терминале — фронтенд
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173

### 3. Запуск через Docker

```bash
cp .env.example .env
# Заполнить .env

docker compose up --build
```

Откройте http://localhost:5173

## Расширение для VS Code

В папке `extensions/vscode-alice-ide/` находится расширение для интеграции в VS Code / Code-OSS:

```bash
cd extensions/vscode-alice-ide
npm install
npm run compile
```

Затем запустите бэкенд и откройте палитру команд (Ctrl+Shift+P) → «Alice: Открыть чат». Расширение отправляет контекст текущего файла/выделения в чат и позволяет применять сгенерированный код.

## Расширение (MVP+)

Для добавления RAG (поиск по коду):

1. Установить PostgreSQL с pgvector
2. Добавить индексацию файлов проекта
3. Использовать Yandex Embeddings API или локальную модель через Ollama

## Замечания

- Используется **YandexGPT**, а не потребительская «Алиса» — у «Алисы» нет публичного API для разработчиков
- YandexGPT может уступать GPT-4/Claude в сложных задачах, но подходит для типичной разработки
